01 / What it does

Built as much around not losing your work as around editing fast.

01

Cell-level rendering

The renderer keeps a grid and writes only cells that changed. A cursor move emits no buffer bytes; a one-line scroll uses a scroll region.

02

1 GiB files

Large-file mode streams decoding into the rope above 20 MiB. A generated 1 GiB fixture opens in 1.9 s at 1.165× resident memory.

03

Saves that cannot truncate

Temp file, fsync, rename over the target, directory fsync. A failed write leaves the original exactly as it was.

04

Crash recovery

Checksummed swap files for named and untitled buffers, with stale-writer detection. vanta -r brings the work back.

05

A real Vim grammar

Counts, operators, text objects, registers, macros, dot-repeat, Visual Block, Select mode and a persistent undo tree.

06

Nothing hidden

No telemetry, no update checks, no network access. MIT licensed. One process, one terminal.

Install from source
$ git clone https://github.com/DrxvenBSD/vanta.git
$ cd vanta
$ cargo install --path crates/vanta --locked
Recover after a crash
$ vanta -r            # newest untitled swap
$ vanta -r notes.md   # a named file's swap

05 / Install

One binary on your PATH. Rust 1.90+ only if you build it yourself.

Windows · prebuilt
Get-FileHash .\vanta-*.tar.gz -Algorithm SHA256
tar -xzf vanta-0.2.0-alpha.2-x86_64-pc-windows-msvc.tar.gz

Every release ships SHA256SUMS.txt. Archives are unsigned for now.

What is not there yet
  • No configuration file, Lua API or plugins.
  • No syntax highlighting, LSP, Git or picker.
  • No :map/:nmap mapping engine yet.
  • Search is literal: no regex, :s or :g.
  • No marks, jumplist, changelist or quickfix.
